# 25Assist policy feed

The `AssistVer` anti-cheat policy (`ver.htm`) that the 25Assist launcher downloads.

The launcher reads `https://raw.githubusercontent.com/AAO25/25assist-policy/main/ver.htm`
and falls back to `https://aao25.com/assistdl/Data/8.23/ver.htm`.

Do not edit this repository by hand. The source is `policy/ver.htm` in the launcher
repository, and its deploy workflow publishes it here when it changes.
